Configurações (ESP32 · backend · dispositivo)

Alterne o modo acima para escolher quem registra o objeto: em MODO ESP32 o pedido vai para o ESP32 (GET /cor + GET /processar) e é o ESP32 que envia o objeto ao backend depois de parar a esteira por ~2s. Em MODO BACKEND o próprio simulador envia POST /api/objetos — use apenas para testar o backend sem o ESP32.

Se o ESP32 não responder, confirme que o celular está na mesma rede Wi-Fi do ESP32 e que o firmware envia o cabeçalho Access-Control-Allow-Origin (a página e o ESP32 são origens diferentes para o navegador).
